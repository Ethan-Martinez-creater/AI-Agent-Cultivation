## Evidence levels and disposition

Unit proof checks deterministic behavior. Integration proof checks real adapters/SQLite/files with controlled dependencies. Windows packaged proof uses actual Electron executable and native SQLite. Live external proof requires a real remote service and explicit user authorization; none is claimed here.

Before finalization, each pending row will be linked to concrete inspected assertions and this round's evidence in `risk-register.md`, `recovery-matrix.json`, and the final acceptance index. BLOCKER/HIGH confirmed defects must be repaired and regression-tested; missing live infrastructure is a separate R6.2 release prerequisite, not offline PASS.

## Initial capacity observation

The frozen USER editor permits 32 total Steps and import requires a following executable Step. Import also allows at most 16 distinct sources and forbids one source impersonating multiple outputs. Therefore the reachable import prefix is bounded by all three constraints, not the standalone formal 32-prefix array bound. Tests will report the actual limit without changing any budget.
